# Spring Boot Management System - Frontend

This repository contains the web frontend for a Spring Boot management system. It
provides the user interface for managing application data through the Spring
Boot backend APIs.

## Technology

- React
- TypeScript
- Vite

## Local Development

### Prerequisites

- Node.js and npm

### Installation

Clone the repository, then install the project dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Vite will display the local URL in the terminal.

## Available Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the development server |
| `npm run build` | Type-check and create a production build |
| `npm run lint` | Check the codebase for linting issues |
| `npm run preview` | Preview the production build locally |

## Production Build

To create a production-ready build:

```bash
npm run build
```

The generated files are placed in the `dist` directory.
